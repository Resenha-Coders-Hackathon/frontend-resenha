# Kit lean — Vue 3 + TypeScript

Base documental para um **único frontend Vue 3 + TypeScript**, organizado por domínios dentro de `src/`. Não cria pastas de aplicação automaticamente nem presume uma arquitetura já existente.

**Fluxo padrão:** uma Issue → uma branch → commits incrementais → testes → Pull Request → integração. Orquestração com vários agentes é uma escolha individual e opcional. Dashboards, GitHub Projects e consultas automatizadas de tarefas também são possibilidades futuras.

## Como aplicar
1. Inspecione o repositório real antes de adotar a estrutura exemplificativa de `docs/MODULES.md`.
2. Preencha `docs/PROJECT_GUIDE.md` com versões, comandos e configuração existentes.
3. Confirme com a equipe os limites de `src/modules/`, `src/shared/` e `src/app/`.
4. Ajuste responsáveis, branch-base, templates e testes automatizados.
5. Leia `AGENTS.md` e `docs/TEAM_WORKFLOW.md` antes de delegar uma tarefa.

Este pacote contém documentação e modelos de GitHub, **não o código de uma aplicação Vue**.
